语音播报

关闭后回复不再朗读（文字照常）

记忆压缩

原始消息估算 token 超该值就压缩（唯一触发条件）
批次超过该大小就切成多片分别压缩——叶子更细、探索回原文更容易；0 = 关闭分片（整批压）
压缩后保留最近多少条原文
某层节点达到多少个开始向上合并
每次合并几个节点为 1 个
整节点总字数目标（默认 1000 ≈ 1000 字，会写进压缩指令；超出软裁剪）

压缩示意图

黑色折线 = 每次压缩触发前的上下文峰值（触发预算 ≈ 等价条数 × 360 + 节点 × 500 token）· 横轴为对话轮数（线性）
拖动平移 · 滚轮缩放 · 双击重置 · 输入上面的压缩参数后即时重算。

模型 API

两个服务商的 Key / 模型 / 端点**分别保存**，切换服务商互不覆盖；留空项用预设或环境变量。

思考

回答前先想一遍会让复杂问题答得更好，简单问题则纯属多花时间——自适应就是让它自己判断。
关闭时官方会忽略「想多久」（实测推理 token 真的是 0，同一道题快约 30%），复杂问题会明显变差。
档位差别在难题上才明显，简单问题三档几乎一样。

代码工作区

启用后小助可以读写该目录下的代码：区内读取免审批；写操作与区外读取会弹出审批窗（超时默认拒绝）。 敏感文件（.env / 私钥 / .git 内部）永远拒绝。更换工作区会清空已记住的审批规则。
提示：工作区变更后「保存设置」才生效；目录只读授权在左上「权限」页管理 （data/permissions.db），旧版「记住并允许」的单文件/命令规则见 data/permissions.json。

已记住的授权规则

「记住并允许」留下的规则；删除后对应操作会重新弹审批（删除立即生效，不用保存）。

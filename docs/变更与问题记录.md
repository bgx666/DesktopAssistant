## 问题复盘

### 2026-10-22 / v0.1.292 — 停止后 Connection error（共享 HTTP client）

- **现象**：点停止后，后续请求报
  `调用模型失败（deepseek / deepseek-flash）：Connection error.`
- **真正堆栈**：
  `RuntimeError: Cannot send a request, as the client has been closed.`
  → `openai.APIConnectionError: Connection error.`
- **根因**：`langchain_openai` 在不传 `http_client` 时，多个 `ChatOpenAI` 实例会复用
  **同一个底层 httpx client**。v0.1.290 的“停止立即关闭 root_client”把旧模型 client
  关掉后，新模型、White 模型、压缩模型拿到的都是同一个已关闭 client；之后每次请求
  都失败。看起来像网络/Key 问题，实际是连接对象被误关。
- **排除项**：直接用同一个 DeepSeek Key 请求 `/chat/completions` 返回 **200**
  （`deepseek-flash` 可用）；OpenCode 也返回 200，网络/Key/模型均正常。
- **修复**：`llm.build_chat_model()` 每次创建**独立 `httpx.Client`**（timeout 按
  `LLM_TIMEOUT`、`follow_redirects=True`），作为 `http_client=` 传入；停止只关闭
  当前模型自己的 client。新增
  `test_build_chat_model_instances_have_independent_http_clients`。
- **验证**：425 passed；完整 e2e 全绿；release v0.1.292。
- **相关**：`src/planner/llm.py`、`src/planner/session.py::_abort_llm`、
  `tests/test_llm_provider.py`。

### 2026-10-22 / v0.1.291 — White 状态一直“运行中”（e2e）

- **现象**：面板检查里 White 结果卡已经出现（含“White 测试任务完成”），但
  `#white-state` 一直显示“运行中…”，最后 `STATE_BAD`。
- **根因**：mock 的「白色任务」触发词用的是**全历史** `last_user`；White 完成后
  主助手收到 `white_finished` 通知，又因为历史里仍有“白色任务”而重复派活，
  White 队列里出现第二个任务，所以第一个结果卡出来后状态仍是运行中。
- **修复**：mock 只认**最后一条真实用户消息**（最后一条是 human 且包含“白色任务”）
  才派活；不改变真实模型的主助手逻辑。e2e 直连面板 33 步恢复全绿。
- **验证**：424 passed（当时）；release v0.1.291。
- **相关**：`src/planner/llm.py`（MockChatModel）、`tests/cdp_panel_check.js`。

### 2026-10-22 / v0.1.290 — 停止要等模型/API 超时

- **现象**：点停止后没有立即停，仍要等模型返回（甚至等超时）；主助手和 White 都有。
- **根因**：原来只置停止标志，`_run_agent`/`_run_once` 只在**收到下一个流事件**时
  检查；模型调用卡住时没有事件，检查不到，只能等 `LLM_TIMEOUT`/重试或 White 总超时。
- **修复**：
  - 主/White 各自拥有独立模型实例；停止时关闭各自模型的 `root_client`，httpx
    在途请求立刻断开；`ReadError` 按“用户停止”收尾，不弹错误 toast。
  - White 停止还会清空任务队列、取消审批等待；总超时改为看门狗，到点也走关闭。
  - 正在写的文件工具先写完；已有消息/工具结果/文件保留；流式中断的半句只留面板、
    不落 buffer。
- **验证**：两个“永久阻塞”假模型测试，停止后 <1s 返回；424 passed。
- **后续故障**：这个版本的关闭动作触发了 v0.1.292 的共享 client 问题（见上）。
- **相关**：`src/planner/session.py`、`src/planner/white_agent.py`、
  `tests/test_agent.py`、`tests/test_white.py`。

### 2026-10-22 / v0.1.289 — DeepSeek Fetch 404 冷却误伤

- **现象**：White 抓网页慢；日志里 DeepSeek 官方 `/v1/tools/fetch` 出现 404。
  一开始误判为“Key 没权限”。
- **用户纠正**：主 Agent 可以正常使用 DeepSeek 服务搜索。
- **实测**：`/v1/tools/search` 200；`/v1/tools/fetch` 抓 javaguide 200；只有
  `raw.githubusercontent.com` 返回 **404 failed to fetch URL**。即 404 是**单 URL**
  失败，不是账号级不可用。
- **修复**：冷却只对 **401/402/403**（鉴权/余额/权限）生效，404 不再整体关闭官方
  链路；内置抓取超时保持 12s。
- **验证**：`test_web_tools.py` +1（404 不冷却 / 402 冷却）；release v0.1.289。
- **相关**：`src/planner/tools.py`、`tests/test_web_tools.py`。

### 2026-10-22 / v0.1.288 — White 页面看不到执行流；标签页不常驻

- **现象**：点开 White 只看到任务说明/最新一条，thinking、工具、执行过程不显示。
- **根因**：
  - 实时事件只在 White 标签页激活时才渲染；切换时又用 `/history` 重载，晚到的

  - 实时事件**始终写入** White 视图（隐藏时也累积）；正在运行时切过去保留现场、
    不重载；历史加载带 token，旧响应不覆盖新事件。
  - 标签页常驻：无任务时显示灰色呼吸灯 + 空态提示；close 后回到灰灯，不删 tab。
- **验证**：用 release 真实 `white.json`（25 条消息）实测：17 个块、14 条工具行、
  thinking、结果卡全部渲染；v0.1.288 直连面板检查全绿。
- **相关**：`frontend/renderer/app.js`、`frontend/renderer/style.css`、

### 2026-10-22 / v0.1.293 — 主助手回答完标签仍转圈

- **现象**：正文已经显示完，Agent 标题栏里的「小助」标签仍在转圈。
- **根因**：标签状态来自 `/agents`，而前端只在启动、展开面板、审批事件时拉取；
  生成结束没有刷新。若 `/agents` 恰好在生成中返回，`status=running` 会一直留着。
- **修复**：`thinking` 事件和 `/state` 的 `thinking` 变化时立即同步主标签；
  `refreshAgents()` 返回后用本地 `isGenerating` 覆盖快照里的 main 状态，
  防止晚到的响应把已结束改回 running。
- **验证**：直连面板通过；全量 425 passed；release v0.1.293。
- **相关**：frontend/renderer/app.js（`syncMainAgentStatus` / `refreshAgents`）。

### 2026-10-22 / v0.1.297 — White 对话区自动拉底，用户无法停留

  `switchAgent('white')` 在 DOM 已有实时内容时不再重复拉 history。
- **验证**：CDP 新增 White 滚动断言；WHITE_OK；完整 e2e；release v0.1.297。
- **相关**：frontend/renderer/app.js、style.css、index.html、tests/cdp_panel_check.js。

### 2026-10-22 / v0.1.299 — 空输入框打开时偶尔很高

- **现象**：打开面板、输入框为空时，高度有时很高；输入框和下方 chips 同容器。
- **根因**：v0.1.298 的 `window.resize -> autoResizeInput` 在面板展开/布局未稳定时
  测到空 textarea 的 `scrollHeight` 偏大；`#composer-bar` 的 `flex-wrap: wrap`
  还会因 chips 异步变长而换行。
- **修复**：空值直接回到 CSS 的 34px，不读 `scrollHeight`；发送后也走该路径；
  面板展开后校准一次；chips 改为单行横向滚动（隐藏滚动条）。
- **验证**：CDP `INPUT_GROW_OK 34/111/216/34` 并断言初始输入条不过高；428 passed；
  完整 e2e；release v0.1.299。
- **相关**：frontend/renderer/app.js、style.css、tests/cdp_panel_check.js。

### 2026-10-22 / v0.1.300 — 目录读授权管理

- **需求**：数据库管理可读目录（递归，父目录覆盖子目录），主窗口独立「权限」页；
  助手可申请目录读权限，用户同意后写库并同步页面；写仍只允许当前工作区。
- **实现**：

    父目录覆盖子目录，列表合并显示（`covered_count`），显式子目录行保留，
    删除父授权后子授权重新出现；
  - 新「权限」页 + `/dir-permissions` API（GET/add/remove/clear）；选择目录、
    显示只读/递归/来源/合并数量、移除；
